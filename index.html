The local lock is intended to prevent casual access, not to provide banking-grade encryption. Anyone with access to browser storage or the device may be able to bypass it. Do not use it as your only protection for highly sensitive information.

Backup and data

Export your data before switching browsers or devices.

Your financial records are stored locally in this browser. Private browsing, clearing browser data, or using a different browser/device may make them unavailable. Export backups regularly. The optional server API can store an encrypted cloud backup when a PostgreSQL database and encryption key are configured; this app build does not currently provide an in-app account or sync control.
