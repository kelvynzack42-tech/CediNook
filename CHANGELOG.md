# Changelog

## 1.0.0 — CediNook
- Renamed to **CediNook** with a new blue, white and light-green look, new icons and artwork.
- Opens straight to the dashboard after the welcome page (no login or register).
- Side-panel navigation: collapsible on desktop, slide-out drawer on phones and tablets.
- Dashboard: getting-started card, monthly summary, bill and goal alerts, backup reminder.
- Savings goals show Ahead / On track / Behind plan.
- Mobile money (MoMo) account type.
- Fixed: scripts that stopped the app from running, overlapping layout, and removed obsolete code and styles.
- Data saved under the old name is migrated automatically the first time CediNook opens on a device.

## 1.1.0 — Daily finance workflow
- Added transaction search, type and month filters, in-place editing, duplicate warnings and delete confirmation.
- Added monthly recurring reminders that only create an entry after the user selects Record now.
- Added dashboard alerts for category budgets approaching their limits.
- Added backup status and a restore contents preview; preserved recurring reminders in JSON backups.
- Clarified local storage and the current cloud API configuration in Settings and README.
- Updated the service-worker cache version so installed apps receive the update.


## 1.2.0 — CediNook visual refresh
- Reworked the workspace around a forest-green navigation rail, calmer page background, sticky header and consistent white content cards.
- Refined dashboard hierarchy, summary cards, forms, action buttons and responsive spacing across finance pages.
